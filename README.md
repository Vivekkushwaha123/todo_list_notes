# todo_list_notes
 Task Flow - Premium Glassmorphism To-Do Application

A modern, responsive, and visually stunning To-Do List web application designed with a deep cosmic dark aesthetic, multi-color ambient mesh gradients, and frosted glassmorphism UI elements. Built with clean HTML5, custom CSS3, Bootstrap, and vanilla JavaScript with localStorage persistence.

🌟 Key Features

✨ Premium Glassmorphism UI: Features frosted glass cards (backdrop-filter: blur), subtle borders, and an ambient cosmic mesh background with purple, cyan, and amber gradient accents.

💾 LocalStorage Persistence: Tasks stay saved locally in your browser so you never lose your task data on refresh or browser exit.

🏷️ Dynamic Filtering: Seamlessly switch views between All, Active, and Completed tasks.

⚡ Live Task Counter: Automatically tracks and displays the number of active tasks remaining.

🧹 One-Click Cleanup: Quickly clear all completed tasks with the "Clear Completed" action button.

📱 Responsive Layout: Perfectly optimized for all display sizes including mobile phones, tablets, and desktop displays.

🛡️ XSS Protection: Sanitizes user inputs before rendering tasks to ensure safe execution.

🛠️ Tech Stack

Markup: HTML5 (Semantic Structure)

Styling: CSS3 (Glassmorphism, Radial Mesh Gradients, Flexbox)

UI Framework: Bootstrap 4.5.2

Icons: FontAwesome 6.5.2

Scripting: JavaScript (ES6+, LocalStorage, DOM Manipulation)
